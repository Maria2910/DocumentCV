# Детекция и распознавание зон на документах, удостоверяющих личность

Проект находит на изображении документа **фотографию лица** и **машиночитаемую зону (MRZ)**, 
вырезает их и распознаёт текст MRZ через Tesseract OCR.

## Как работает
1. **YOLO26** находит на документе две зоны: `photo` и `mrz`.
2. Каждая зона вырезается в отдельный файл.
3. **Tesseract OCR** распознаёт текст MRZ.
4. Для каждого документа создаётся отдельная папка с результатами.

## Технологии
- YOLO26 (Ultralytics) — детекция зон
- X-AnyLabeling — разметка данных
- Tesseract OCR 5.5 — распознавание текста
- OpenCV, Python 3.11

## Установка
pip install ultralytics opencv-python pytesseract
Также нужен Tesseract OCR (английский язык)

## Запуск
1. Положить документы в папку incoming/
2. Запустить обработку
python main.py
3. Результаты появятся в output/

## Результат обработки
Для каждого документа создаётся папка:
output/<имя_документа>/
├── <имя_документа>.jpg   # исходник
├── face.jpg              # вырезанное фото
├── mrz.jpg               # вырезанная MRZ
├── mrz.txt               # распознанный текст
└── boxes.txt             # координаты боксов

## Датасет
Обучение — на синтетических канадских паспортах
(Kaggle), 96 изображений,
два класса: photo, mrz.

Проверка — на японских паспортах (эти данные не участвовали в обучении).

## Результаты
Класс	Precision	Recall	mAP50	mAP50-95
all	0.999	1.000	0.995	0.870
photo	0.998	1.000	0.995	0.926
mrz	0.999	1.000	0.995	0.814
Обучение: 50 эпох, YOLO26n, CPU, ~27 минут.

Проверка на новых данных: 20 из 20 японских паспортов обработаны корректно.
